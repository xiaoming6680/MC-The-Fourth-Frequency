# 《第四频段》世界观圣经

本文描述 `1.0.0-rc.1` 的现行叙事边界。数值与测试以 [世界接口终局](world-interface.md) 和 [测试与验收](testing.md) 为准。

## 核心命题

世界并非突然被外来怪物入侵。它一直在用玩家熟悉的方块、菜单、声音和规则维持一层可理解的外观，而“第四频段”是这层外观无法完全压住的通信噪声。

终端不是任务列表的外壳，而是世界用有限带宽解释自身的接口。它先学会记录玩家，再学会回答；当回答越来越准确，世界也越来越难继续假装一切正常。

## 不可动摇的事实

- 零号站与终端是故事入口，终端是玩家唯一稳定的解释工具。
- 生存主线仍建立在原版行动上：木材、铁、下界、烈焰棒、末影之眼、要塞和末地。
- 四份破损文件来自对原版世界遗迹的调查，不依赖额外生成的“四处设施”。
- 异象不是随机彩蛋合集；它们按 1—5 层逐渐从环境误差走向界面和规则层。
- 校正者以五种个人形态学习玩家的声音、路线、预测、空间和界面；它是世界接口学习“如何使用身体”的前置证据，不是最终敌人的低级血条版本。
- 正式追逐发生在与其他玩家隔离的私人校正层。孤独感来自观察者被暂时从共享现实中摘除，而不是让其他玩家假装看不见。
- 最终战是多人共同提交解释权的仪式：每个参战者都必须交出自己的绑定终端。

## 体验曲线

### 1. 可信的旧版本

第一次进入世界时，客户端完成一次 Alpha 风格降级：资源包按 Programmer Art → Golden Days Base → Golden Days Alpha 管理，加载界面与版本文案把熟悉的游戏拉回一个不完全真实的 “Minecraft 1.0.0”。

它应首先让人怀疑版本和记忆，而不是立刻宣告恐怖主题。

### 2. 可重复的误差

异象从声音、光线、方块和记录上的小偏差开始。服务器只决定“发生了什么”，客户端决定“目标玩家如何感知”；多人可以共享发现，却不必共享同一幻觉。

终端的语言应保持短、冷静、像一台努力压低噪声的仪器。它可以不完整，但不能用全知旁白替玩家下结论。

### 3. 世界开始记录玩家

住所、矿物、传送门、天气、导航和要塞工具逐渐从扫描器变成证词。三次真实末影之眼投掷尤其重要：世界接口不是凭空给坐标，而是在承认玩家已经证明过方向。

天气工具是这条曲线上最早、也最容易被忽略的一格：它开局就有，平时只报天气与时间。但它同时监测天空的四个通道，所以当天开始被改写时，它是第一个知道的东西——也是第一个开始失去信号的东西。

FILES 中的隐藏文件把零散现象连接成同一套身体/接口映射，但保留解释空间。玩家应逐渐意识到：所谓“异常”也许只是世界无法继续用原版词汇描述自己的时刻。

### 4. 私人校正层

普通异象先以安全方式演示校正者下一形态的规则；终端随后把观察转译成可执行的短警告。正式追逐才把玩家送入与当前维度对应的私人镜像。

镜像不是另一个可以开采的世界。它复制玩家附近的现实并沿逃跑路线继续展开，但容器、战利品、其他玩家和真实进度都被剥离。玩家可以开路和临时放置，却不能从虚假地形中带回资源。这里的叙事边界是：

> 世界不是真的，但受到的伤害是真的。

校正者五形态不是单纯加速：

- 寻声者把重复行动解释成位置；
- 定向者把常走路线解释成意图；
- 截断者把移动趋势解释成未来出口；
- 越界者不再接受墙壁和天花板作为边界；
- 接口校正者开始伪造坐标、文字和方向；心跳只表示它在哪、有多近，不会指出出口。

玩家提前推进主线不会被连续追逐惩罚。世界只保留下一次校正机会；每个形态都必须先被看见、被终端解释，再进入正式对抗。

### 5. 集体交出终端

末地祭坛贴合原生主岛，因为终局必须发生在玩家认识的世界里。20 座惰性门像未启用的出口，10 个稳定锚像世界仍在拒绝崩溃的局部承诺。

冻结参战名单和逐人提交终端具有叙事含义：没有任何一个客户端能单方面代表所有观察者。提交前可以撤回，提交后则进入共同承担的事务。

## “第四频段·世界接口”

世界接口不是传统意义上的肉身。三种形态是同一接口在受压后逐步放弃可读性的表现，形态只能向前，不能因治疗退回。

稳定锚也不是简单的“先拆塔”。它们会治疗并重构目标的外壳，让它更难受伤、出招更迟，同时在柱脚留下能减轻接口伤害、拒绝地形侵蚀的稳定区。拆除会暴露接口并停掉一份回血，却让它出招更密，也熄灭一块安全地面；它的移动速度与固定崩塌倒计时都不受锚影响。这种选择应让玩家争论，而不是照着唯一攻略执行。

八类行动围绕“世界怎样解释玩家”展开：

- 激光、龙息弹与天降光束把空间和弹道变成协议回声：三者都可以靠移动规避，代价是必须先读懂它在看谁。
- 抓取投掷暂时夺走位置解释权，但必须给出预警，且整段搬运都要看得见——被举起来和被瞬移走是两种完全不同的恐惧。触手先把人甩出本体轮廓之外才松手，落地怎么活是玩家自己的答案，不是接口替他写好的结局。
- 触手抽击是接口唯一的近身语言：它不解释玩家，只是把玩家推开。
- 武器扣押和凝视清栏暂时接管物品叙事。扣押物留下一枚写明状态的占位屏障并进入恢复账本；清栏则把东西真的丢在地上，谁都能捡——恐惧来自失去控制，不来自暗中吞物。
- 强制驱逐把连接本身当作攻击，但不会选取集成服务器房主，也不能让 LAN 世界被一个客户端演出终止。

世界接口能给末地留下永久伤痕，但伤痕必须有限、可解释并避开原版关键结构与存活锚投射的稳定区。它不能摧毁稳定锚，也不能借“Meta”之名无上限地修改玩家世界。

## 两种结局

### 成功：在解释坍塌前切断接口

玩家在倒计时结束前击败世界接口。祭坛开放返回出口，原版终末之诗的通道被用于呈现本次成功诗篇、制作人员名单与片尾；诗篇会记住他们保全了全部、部分还是没有任何稳定锚。只有诗篇完成且玩家真实返回主世界后，长期受限的视距才从 6/12/16（其他维度 12）解锁到 16。

这不是回到一切发生前：战场伤痕仍在，标题页结局锁也承认这段世界已结束；成功存档被称为“存档已封存”。从结算开始，普通异象、空档补压、衰减和追逐全部永久沉默，不再为故事追加伪造的尾声。

### 失败：接口跨过客户端边界

崩塌先完成时，世界接口进入逃逸解析。客户端不会被关闭：固定演出结束后，原版回程把玩家送回主世界，本地整个世界变成缺失材质，屏幕下方提示流程已结束。若失败者是已发布 LAN 的房主，服务器同样继续存在，客人看到的方块和规则不变。

失败不是破坏操作。恐怖效果属于客户端演出和无损标记，不允许改写 `level.dat`、区块或玩家数据；失败存档被称为“存档已损坏”。失败者可从暂停菜单自行退出，重新启动后 Alpha 呈现会保留到 F8 恢复完成。

## 结局锁、F8 与重玩

两种结局都使标题页只禁用三个进入世界的入口：单人游戏、多人游戏和 Realms。设置、辅助功能和退出仍然存在，这是玩家安全退出和恢复的边界。

F8 只有在持久结局锁存在时才按成功/失败结果打开对应的确认。确认恢复 MOD 持有的桌面、记事本、窗口和资源包状态，然后正常关闭。再次启动时，准确对应的本地结局存档通过 `.thefourthfrequency-corrupted` 标记隔离：成功显示“存档已封存”，失败显示“存档已损坏”；新一次故事必须从新世界开始。

`-Dthefourthfrequency.safeMode=true` 是演出中断后的恢复后门，不是叙事捷径。

## 写作与视听边界

- 终端文案短句优先，先给可操作信息，再给不完整解释。
- 不用虚假的系统错误替代规则提示；重要控制必须有清晰预警。
- 恐怖来自熟悉系统被重新解释，不来自无提示删档、吞物或无限制改桌面。
- 高对比、闪烁和峰值音量受首次安全告知与配置边界约束。
- Meta 效果只能改变 MOD 明确持有或可恢复的本地状态；多人服务端权威数据不受客户端幻觉污染。

界面演出（如天气工具的天空监测）另受三条硬规则约束：

- **可操作信息只会可见地失效，不会静默出错。** 玩家会照着“约 N 分钟后天黑”走回家，所以异象可以夺走这个数字，但不能换给他另一个同样可信的数字。仪器读数没有生存决策挂靠，才可以自由爆表与乱跳。
- **故障文案用仪器自己的语言，不伪造异常与堆栈。** 伪造的崩溃既踩中上面“虚假的系统错误”那条，也会让玩家以为游戏真的坏了。恐怖是一台设备正在失去天空，不是一个软件出错。
- **退出路径只能被一次性的、有终点的引导暂时接管，闪烁不超过 3 Hz。** 页面标签、返回按钮与关闭提示在任何常规阶段都不被覆盖；任何可见状态切换至少保持 7 tick。

  唯一的例外是新档第一次打开终端的开机引导。它可以在走完之前不放玩家出去，但必须同时满足四个可测条件：

  1. **一次性。** 服务端单向闩锁，任何情况下都不重放；旧存档按“已经用过终端”回填，不补看。
  2. **有确定终点。** 四步，每一步都由玩家自己的点击推进；客户端不能替玩家推进，也不能凭自己“播完了”就结算任务。
  3. **有安全解除。** 玩家一旦受到伤害立即解锁并保留进度。终端不暂停世界，所以“关不掉”在挨打时等于“打不还手”。
  4. **服务端可越过。** 强制关闭永远优先于引导锁定。

  锁定期间关闭提示必须换成“当前无法退出”的说明。屏幕上写着“按 Esc 退出”而 Esc 无效，正好踩中上一条“不静默出错”。任何非一次性、无终点或无解除条件的锁定都不被允许。这些条件由单元测试断言，不是靠自觉。
